# Student-Marks-Analyzer-Python
A beginner-friendly Python project that calculates student total marks, average, percentage, and pass/fail status using user input, arithmetic operations, and conditional statements.

## 📌 Project Overview

The Student Marks Analyzer is a simple Python program that accepts a student's name and marks in five subjects. It then calculates the total marks, average, percentage, and final result.

## 🚀 Features

* Accepts student name
* Accepts marks for 5 subjects
* Calculates total marks
* Calculates average
* Calculates percentage
* Determines Pass/Fail status
* Displays results using formatted output

## 🛠️ Technologies Used

## ▶️ How to Run

Make sure Python 3 is installed.

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/student-marks-analyzer.git
```

Navigate to the project directory:

```bash
cd student-marks-analyzer
```

Run the program:

```bash
python student_marks.py
```
